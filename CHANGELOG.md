# Changelog

## 2.0.3

- Имя роли переживает чистку дублей: `prune` переносит `label` мёртвой записи на
  живую запись той же роли.
- `bind` берёт имя с любой записи роли, а не только с выжившей.
- Стабильное определение времени старта процесса: повтор опроса и кэш на 5 секунд.
- `prune` мемоизирует статус `lease`, два участника одной сессии получают один
  вердикт.

## 2.0.2

- Повтор и кэш времени старта pid убирают ложную смерть живого окна.
- Один вердикт `sessionStatus` на `lease` при чистке привязок.

## 2.0.1

- `bind` без `--allow-other-session` привязывает только своё окно.
- Upsert по канонической роли: одна привязка на роль, сохранение `participantId` и
  имени.
- `/house setup` передаёт `--allow-other-session`; `/house say` берёт
  `participantId` из конфига.

## 2.0.0

- Каталог дома называется `.house` во всех командах и документации.
- Обновлены документация и сценарии установки.
